# Software Development Assessment — Portfolio Demo

Een geanonimiseerde portfolio-demo van een interactieve assessment, omgebouwd
van een commerciële schrijf/boekcase naar **software development**.

## Wat laat dit project zien?

- Responsive HTML/CSS UI
- Interactieve meerstaps quiz
- Scoreberekening en profielbepaling
- Browser history / back-button ondersteuning
- Dynamisch resultaat
- JavaScript event handling
- Een gesimuleerde data-submit flow
- Scheiding tussen frontend en Apps Script voorbeeldcode

## Privacy & veiligheid

Deze repository bevat bewust **geen echte bedrijfsgegevens, API-keys,
CRM-endpoints, checkout-links of persoonsgegevens**.

De submit-functie in `index.html` doet in deze portfolio-versie geen externe
HTTP-request. De Apps Script-code is eveneens een veilige demo-stub.

> Gebruik voor een echte productie-integratie environment/secrets management
> en commit nooit API-sleutels naar een publieke repository.

## Lokaal bekijken

Open `index.html` in een browser of host de repository met GitHub Pages.

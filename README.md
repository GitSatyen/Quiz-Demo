# Software Development Assessment

Een interactieve webapplicatie waarmee gebruikers door middel van een assessment een persoonlijk software development-profiel krijgen.

Dit project is ontwikkeld als portfolio-demo en laat zien hoe een interactief concept kan worden vertaald naar een complete digitale oplossing met frontend-logica, dynamische resultaten, API-koppelingen en automatisering.

## 🚀 Functionaliteiten

* Interactieve assessment met meerdere vragen
* Dynamische verwerking van gebruikersinput
* Persoonlijk resultaat op basis van gegeven antwoorden
* Responsive ontwerp voor desktop en mobiel
* Dynamische content en resultaatprofielen
* Voorbereid op koppelingen met externe API's
* Google Apps Script als backend/tussenlaag
* Mogelijkheid om resultaten en gebruikersgegevens door te sturen naar externe systemen

## 🔌 API & MailBlue integratie

De oorspronkelijke applicatie is ontwikkeld met een integratie richting **MailBlue**.

Via een **Google Apps Script-verbinding** kan de frontend communiceren met een backendlaag, waarna gegevens via een API kunnen worden verwerkt en doorgestuurd naar MailBlue.

Een dergelijke integratie kan bijvoorbeeld worden gebruikt voor:

* Het aanmaken of bijwerken van contacten
* Het koppelen van gebruikers aan specifieke tags
* Het doorsturen van assessmentresultaten
* Het starten van geautomatiseerde marketingflows
* Het verbinden van een interactieve webapp met bestaande bedrijfsprocessen

Voor deze GitHub-portfolio-versie zijn alle echte API-credentials, bedrijfsgegevens en productie-endpoints verwijderd. De integratie is daarom als veilige demo-structuur opgenomen.

## 🔐 Privacy & security

Dit project is geanonimiseerd voor publicatie op GitHub.

Er zijn **geen echte API-sleutels, wachtwoorden, bedrijfsgegevens of productiecredentials** opgenomen in deze repository.

API-credentials horen uitsluitend server-side en veilig opgeslagen te worden en mogen nooit rechtstreeks in frontend-code of een publieke GitHub repository worden geplaatst.

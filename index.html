Demo Company - Online Assessment

Hoe sterk is jouw software development aanpak?

Goede vraag. Sterke software ontstaat niet alleen door code te schrijven.

Goede software steunt op vijf bouwstenen: je technische basis, je architectuur, je gebruikers, de koppeling met het product en je beslissingskracht. Goede code zonder duidelijke gebruiker mist richting. Een goed idee zonder technische basis blijft een idee. Pas als de bouwstenen samenkomen, ontstaat software die betrouwbaar, onderhoudbaar en waardevol is.

Deze assessment kijkt naar alle vijf, in 6 vragen en ongeveer 2 minuten. Je krijgt direct een profiel van je development-aanpak.

Er zijn geen goede of foute antwoorden. Kies wat het beste bij jouw manier van software ontwikkelen past.
